# bom_game — 지뢰찾기: 수류탄 에디션

클래식 지뢰찾기 규칙에 지뢰 칸을 수류탄 그래픽으로 표현한 새 버전. 빌드 도구 없이 `index.html` 하나로 동작하며, 정적 호스팅(GitHub Pages 등)에 바로 배포할 수 있습니다.

## 플레이 방법

`index.html`을 브라우저로 열면 바로 실행됩니다.

- 난이도 선택(초급 9x9/10개, 중급 16x16/40개, 고급 30x16/99개) → START
- 좌클릭: 칸 열기 (첫 클릭은 항상 안전) · 우클릭: 깃발 표시/해제
- 숫자는 인접한 8칸의 지뢰 개수, 0이면 주변 칸이 자동으로 연쇄 오픈
- 지뢰 칸을 열면 수류탄 그림과 함께 GAME OVER, 지뢰가 아닌 칸을 모두 열면 CLEAR!
- 상단 HUD: 남은 지뢰 수, 경과 시간, 스마일 버튼(클릭 시 재시작)
- PRD: [PRD.md](PRD.md)
